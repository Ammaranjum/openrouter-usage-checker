Install with `gnome-extensions install --force ~/Downloads/OpenRouterUsage-GNOME.zip`, log out and back in, then run `gnome-extensions enable openrouter-usage-checker@local`.

Fixes **⌘V paste** in the Mac API-key field, in both the settings window and menu-bar panel. Windows and Linux behavior is unchanged.

Mac downloads are ad-hoc signed and not notarized. Windows downloads are unsigned. [Setup help](https://ammaranjum.github.io/openrouter-usage-checker/).

Use the three downloads above. GitHub's automatic source archives are for developers.
